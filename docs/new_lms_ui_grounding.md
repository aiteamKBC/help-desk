# New LMS Learner Workspace UI Grounding

## Learner Workspace / Overview

When a learner says they are on the LMS main page, home page, dashboard, overview, or learner workspace, treat this as the Learner Workspace / Overview page unless the learner describes a different screen.

The Learner Workspace / Overview page shows the learner profile and programme context at the top. Common visible labels include Overview, Learner Workspace, My Learning, Calendar, Evidence & Progress, Attendance, My Progress, Message coach, Continue learning, Programme Progress, Attendance, OTJ Hours, KSB Progress, Upcoming, My Coach, and Next steps.

The main learning activity list is in the Continue Learning section. Continue Learning can contain activity cards such as recorded sessions, reading materials, assignments, podcasts, quizzes, live sessions, and PowerPoint resources. Activity cards can show labels such as Completed, To do, Attempted, Reflection awaiting review, or Content unavailable.

## Finding And Opening An Assignment

If a learner is on the Learner Workspace / Overview page and asks how to submit, upload, complete, or find an assignment, guide them from Continue Learning rather than telling them to use a generic main menu.

Use these grounded steps:

1. On the Learner Workspace, go to the Continue Learning section.
2. Find the assignment activity they need, for example Assignment 7, and open it.
3. On the assignment page, look for the submission or upload area.
4. Choose the file from their device and upload it.
5. If a separate Submit or Confirm button appears, select it to complete the submission.

If the assignment card is greyed out or says Content unavailable, tell the learner the activity may not be available yet and ask them to send the assignment name and the status label shown on the card.

If the learner cannot see the assignment in Continue Learning, ask for the exact activity name or the labels they can see in Continue Learning.

## Submission Language

Use exact LMS labels from the visible UI when they are known. Prefer Learner Workspace, Overview, Continue Learning, assignment activity, Assignment 7, upload area, Submit, and Confirm.

Avoid generic Moodle wording such as open your course from the main menu unless the retrieved context or learner message specifically mentions a course/module menu.
